# 終端機教學圖

這些是根據官方說明與輸出格式製作的教學示意圖，並非學員電腦的實際截圖，也不是本次實際安裝成功的證據。版本、使用者名稱、輸出語言及配色會因環境而異；長輸出只保留教學需要的部分。每個範例的文字與下一步保存在 `scenes.json`。

- `*-wide.png`：桌面版，820 CSS px、2 倍解析度。
- `*-mobile.png`：手機版，360 CSS px、2 倍解析度，長文字自然折行。
- HTML 保留可複製指令、圖說、完整圖中文字版、狀態切換及放大檢視。
- teacher / teacher-demo 與 AB12-CD34 均為示意，不可當作登入資料使用。
